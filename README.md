# pyush.github.io

Root of the GitHub Pages site at https://pyush.github.io/

- `index.html`: home page listing the apps
- `surjam/`, `hokayantra/`, `mathsurge/`: app pages (`/surjam/` is the website on SurJam's Play listing)
- `assets/`: shared stylesheet, icons, screenshots and the "scan to install" QR codes (`qr-<app>.svg`, regenerate with `python3 scripts/make-qr.py`; needs `pip install segno`)
- `app-ads.txt`: checked by AdMob for every app in the account

Privacy policies live in their own repos:
- SurJam: https://pyush.github.io/surjam-privacy/
- Hokayantra: https://pyush.github.io/hokayantra-privacy/
- MathSurge: https://pyush.github.io/mathsurge-privacy/
